# stock bot

## overview

Stock bot is a automated tool for fetching data from the exchanges and use web service to display important info for the users.

## architecture
Backend Service:
- Using Python 3.12
- FastAPI, SQLModel, Redis, RabbitMQ, PostgreSQL and Docker

Frontend Service:
- Using React 18, Echarts and Vite, etc.
- Using Tailwind CSS v4 and shadcn/ui for UI Pages.
