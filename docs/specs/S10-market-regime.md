# S10 市场状态机（Market Regime）

> 交付序 **S10**。**零新表、零新数据源**：全部特征来自 `daily_quotes`（覆盖 834 个交易日，2023-05→2026-10）。
> **定位**：回答"现在市场处在哪个阶段、历史上同阶段的后续分布是什么"，**不预测**。

---

## S10.1 特征（只用全历史可算的）

| 特征 | 定义 | 为什么用它 |
|---|---|---|
| `amount_pctile` | 当日全市场成交额，在过去 250 个交易日里的分位 | 冷热的最稳定量 |
| `adv_dec_ratio` | 上涨家数 / 下跌家数 | 广度 |
| `median_pct_chg` | 当日全市场 `pct_chg` 的截面中位数 | 抗极端值 |
| `new_high_ratio` | 当日收盘创 60 日新高的股票占（有 ≥60 日历史的）比例 | 赚钱效应 |
| `realized_vol_20d` | 全市场中位 `pct_chg` 的 20 日滚动标准差 | 波动状态 |

**口径禁令**：**不使用**涨停/连板族特征（`stock_price_limits` 只有 259 天，前两年算不出来）；若将来要用，必须另立版本并标注覆盖起点。

## S10.2 五态与迟滞

| 状态 | 判定（同时满足） |
|---|---|
| `冰点` | `amount_pctile < 0.30` 且 `median_pct_chg < 0` 且 `new_high_ratio < 0.15` |
| `修复` | `0.30 ≤ amount_pctile ≤ 0.70` 且 `median_pct_chg > 0` 且 `new_high_ratio` 5 日环比上升 |
| `亢奋` | `amount_pctile > 0.70` 且 `new_high_ratio > 0.30` 且 `median_pct_chg > 0` |
| `退潮` | 20 日内 `amount_pctile` 回落 > 0.20 且 `new_high_ratio` 下降 |
| `中性` | 其余（**必须有**：不硬塞） |

- **判定顺序**：`亢奋 > 冰点 > 退潮 > 修复 > 中性`（避免同时满足时不确定）。
- **迟滞**：新状态需**连续 3 个交易日**满足才切换；切换后 `since` 归零重新计。单测必须构造"边界抖动序列"证明不会来回跳。
- 阈值全部进 registry 常量 `REGIME_THRESHOLDS` + `REGIME_VERSION`；改阈值必须 bump 版本。

## S10.3 产物与读面

- 离线脚本 `build_market_regime.py`（**待建**，落 `backend/` 脚本目录）→ `market_regime_history.json`：
  `{version, as_of, series:[{date, state}], transitions:{"冰点":{"修复":0.42,...}}, forward:{"修复":{"n":37,"t5_median":0.8,"t5_p05":-3.1,"t20_median":1.4}}}`
- 统计口径：**同态后续 5/20 个交易日的全市场中位收益**；winsorize ±50%；只用该态**入场日之后**的数据（无前视）。
- `GET /api/v1/market/regime`（登录即可）→
  ```jsonc
  { "state": "修复", "since": "2026-10-08", "duration_days": 7,
    "transition": {"修复": 0.55, "亢奋": 0.2, "中性": 0.15, "冰点": 0.05, "退潮": 0.05},
    "forward": { "5d": {"n": 37, "median_pct": 0.8, "p05_pct": -3.1},
                 "20d": {"n": 36, "median_pct": 1.4, "p05_pct": -6.2} },
    "notes": ["状态由固定规则判定，不预测未来", "每态样本 <30 不给分布"] }
  ```
- **读法纪律（必须写进 `notes`）**：样本期整体有漂移（全市场中位收益长期为负），所以"同态后续中位"的**绝对水平不能单独看**，
  必须与**同期「中性」态**的分布对比；API `notes` 已包含这句（`FORWARD_NOTE`）。
- **UI**：`/me?tab=triage` 顶部一行 `市场状态：修复（已 7 天）｜历史同态 5 日中位 +0.8%（n=37）`，点击展开转移概率与 20 日分布。**不动 `/market`**。

## S10.4 验收判据

- 行为：`classify(features)` 表驱动单测覆盖五态 + 同时满足时的优先级；边界值（0.30/0.70/0.15/0.30）
- 行为：迟滞生效——构造 `冰点→修复→冰点` 各 1 天的抖动序列，状态**不切换**；连续 3 天才切换
- 行为：`series` 与原始 `daily_quotes` 对账（随机抽 5 天重算一致）；`transitions` 每行和 = 1（±1e-6）
- 行为：每态 `n < 30` 时 `forward` 不给数字（`null`），只给 n
- 数据契约：**无迁移**（`grep create_table` = 0）；产物两次运行**逐字节一致**
- 门禁：`self_review --full` + 全量 e2e（regime 行可见、无预测词）

## S10.5 风险

- 阈值是设计选择 → **落地前先跑 834 天分布，确认每态占比 ≥5% 天数**，否则调阈值（这是"先标定再上线"的同一条纪律）。
- 状态机天然滞后（3 日迟滞 + 特征窗口）→ 文案必须写"当前处于"，不得写"即将"。
