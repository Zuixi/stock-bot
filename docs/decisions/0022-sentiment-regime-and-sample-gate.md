# 0022 情绪阶段是启发式描述、小样本不进统计：规则可复核，图不撒谎

```
status:        accepted
date:          2026-10-19
supersedes:    -
superseded-by: -
```

## 背景

用户要把「短线情绪」从"单指标读数"升级为"一眼看懂市场处在周期哪一段"。这带来两个
必须现在拍板的建模问题：

1. **阶段怎么判定**：用 ML/聚类，还是用可复核的规则？阈值定在哪？
2. **小样本怎么处理**：`2进3 = 50%, n=2` 这种点，是照常画进趋势/分位，还是排除？

现状（2026-10-18 真库）：`market_sentiment_daily` 244 天；`2进3` 有 19 天 n<5；
`promo_2to3` 最新一天 n=2、50%。如果把 n=2 的点当普通样本，图上会出现和 200 个样本
一样的尖峰，"信号"其实是噪声。

## 决策

### 1. 阶段 = 启发式规则，不是预测模型

用三个已在日表冻结的维度：涨停家数、炸板率、最高板。每天先算 **PIT 250 日分位**
（只用当天及之前），再按规则判阶段：

| 条件（分位，0–100） | 阶段 |
|---|---|
| 涨停 ≤ 40 家 且 涨停分位 ≤ 25 且 炸板分位 ≤ 60 | 冰点 |
| 涨停分位 < 50 且 炸板分位 ≥ 60 | 退潮 |
| 涨停分位 < 50 | 修复 |
| 涨停 ≥ 80 家 且 涨停分位 ≥ 85 且 最高板 ≥ 5 且 最高板分位 ≥ 80 | 高潮 |
| 炸板分位 < 60 | 发酵 |
| 其余（涨停分位 ≥ 50 且 炸板分位 ≥ 60） | 分歧 |

配套三条：

- **绝对水位守卫**：分位在"窗口内数值几乎不变"时会饱和到 100（20 天全是 20 家也报 100
  分位）。故冰点/高潮额外要求绝对家数/板数，避免把"低位横盘"判成高潮。
- **持续性**：新阶段必须连续出现 2 天才切换，否则沿用上一阶段；但**最后一天以当日原始
  判定为准**（当前状态不能被平滑吞掉），最多产生 1 天的末段。
- **版本化**：阈值改动必须 bump `REGIME_VERSION` 并同步
  `docs/design/limit-up-sentiment.md` §3.7；阶段是**描述性标签**，不是交易信号，UI 必须写明。

**被否决**：KMeans/HMM 聚类（无法复核、阈值不可解释、样本只有 244 天）；用"未来数据"
平滑（前视偏差）。

### 2. 小样本不进统计，但值仍然展示

- 样本型指标定义：晋级率（`promo_*_n`）、昨日涨停均值/今开溢价（`yzt_n`）、炸板率
  （分母 `zt_count + zb_count`）。
- **`n < 5` 的日子**：原始值仍进 `series`（标 `low_sample=true`，图上空心点），但**不进**
  统计量、分位、分布、连续天数；详情页 hero 显示"样本不足"，不给分位。
- 比值类指标在 `n≥5` 时给 **Wilson 95% 区间**；不把小样本点估计当结论。
- 趋势线只连**有效点**（`connectNulls` 跨过低样本日），低样本原始值用空心点展示——线表达趋势，
  点表达事实；两者不能混成"n=2 也画进主线"。

**被否决**：把 n=2 的 50% 当普通点（当前 bug）；用 0 填充（把"算不出"读成"是 0"）；
只在小字里标"样本小"但仍让它进分位。

### 3. 总览用 small multiples + 同分位轴，不用双 Y 轴

- 4 个核心指标（涨停家数、炸板率、最高板、1进2）各一张小图，共享时间轴、hover 联动
  （`echarts.connect`）；详情页再给单指标深挖。
- 情绪 vs 指数：两条线都转成 **PIT 250 日分位**再同轴比较，连续 3 日差 ≥30pp 标背离；
  不使用双 Y 轴（会制造虚假相关）。
- 阶段背景带用 5–7% 透明度；详情页额外给色块图例，避免"彩色背景是装饰"。

## 后果

- 新增 `GET /market/sentiment/pulse`（读时计算、Redis 900s）：9 指标序列 + 阶段区段 +
  基准指数 5 日收益分位 + 背离段；前端「情绪脉搏」区块消费。
- `market_sentiment_daily` 无需新表、无需新 Job；基准只读 `index_dailies` 的
  `399006.SZ` / `000001.SH`（本地未落中证1000，页面只提供这两个）。
- 指标详情响应追加 `low_sample / latest_interval / sample_gate / regime`；老消费方忽略即可。
- 阶段规则与阈值是**可复核的公共契约**：读者可用同一份日表复算；变更须版本化并留痕。
