# 0021 情绪指标：盘后按日冻结、盘中不落日表，历史详情读时计算

```
status:        accepted
date:          2026-10-18
supersedes:    -
superseded-by: -
```

## 背景

用户实测反馈：「短线情绪的温度计能读今天，但每张卡都进不去历史，没法持续追踪」。核对源码与真库
（本地栈 `127.0.0.1:5433`，`market_sentiment_daily` 244 行 / 2025-10-15 → 2026-10-16）：

| 事实 | 证据 |
|---|---|
| 日级聚合**早已在落库**，且覆盖面足够 | `market_sentiment_daily` 244 个交易日、2025-10-15 起无洞 |
| 但**两张卡没有历史** | `yzt_avg_open_premium`（今开溢价）与 `yzt_n`（昨日涨停样本数）每天算出、从未落库 |
| 序列端点**丢掉已冻结的列** | `/sentiment/trends` 的 `sentiment_series_row` 只投影 7 个字段，`yzt_avg_pct` / `promo_2to3` 读不到 |
| 读面**没有单指标入口** | 只有"全量序列 + 3 个指标分位"，没有"某个指标自己的统计/分布/连续天数"；前端卡片不可点 |

所以缺的不是"再建一张表"，而是三件事：**把卡片对应的列补齐、把已冻结的列读出来、给单指标一个读面**。

## 决策

1. **盘后冻结、盘中不写日表。** `market_sentiment_daily` 只由收盘口径（本地自算：`daily_quotes` +
   `stock_price_limits`）写入；盘中口径（东财涨停池）只服务实时读面与 `market_sentiment_intraday`
   这个**分钟级缓存**，不进入日表。理由是口径不同：盘中 `dt_count/zb_count` 无独立信号源、
   `broken_rate`/晋级率无"昨日→今日"语义，写进去会让"每天一个数"的历史混入另一种口径。
   （既有例外：盘中分支在东财失败时回落 close 路径并顺手落 T-1 的收盘行——那不是盘中口径，
   仍是收盘口径写入，故不违反本条。）
2. **卡片与列 1:1。** 温度计有 9 张卡，日表就必须能重建这 9 个数；新增
   `yzt_avg_open_premium`（Float，NULL 允许）与 `yzt_n`（Integer，默认 0），由 `persist_snapshot` 一并写。
   历史行由 `backend/scripts/backfill_sentiment_metrics.py` 只补 NULL 列（不覆写既有事实）。
3. **单指标详情读时计算，不物化。** `GET /market/sentiment/metrics/{metric_key}` 在请求时对
   ≤500 行做统计（min/pXX/median/mean/std、直方图、连续同向天数、分位位置），不新建表、不新建
   Job、不新增写路径。窗口 244 行、9 个指标的量级下，现算的开销远小于"再维护一条会过期的写入链路"。
4. **缺失纪律继续沿用**：NULL 不进样本、不计 0；有效样本 < 60 不给分位；< 5 不给均值/统计；
   < 10 不画分布；未知 `metric_key` 返回 404 而不是空图。
5. **详情页与卡片同鉴权姿态**：`/market/sentiment/:metric` 属 `/market/**`（公开），
   数据来自公开的 `/api/v1/market/sentiment/*`；不把公开看板的历史入口锁进 `research:read`。

## 被否决的方案

- **盘中 5 分钟快照也写日表**：会产生"同一天多行/覆盖语义"，且与收盘口径的数字不可比；
  分钟级需求已由 `market_sentiment_intraday`（缓存，可整日删）承担。
- **每个指标一张表 / 一套指标框架**：9 个指标同属一行、同源同窗口，拆表只会引入 join 与漂移。
- **前端计算统计与分位**：会把"有效样本 / 缺失语义"复制到浏览器，且与 `/sentiment/trends` 的
  既有后端口径分叉。前端只做量纲渲染（ratio ×100）。
- **把详情页做成抽屉/弹窗**：历史追踪需要可分享的深链与刷新后仍可回放，路由页比抽屉更合适。

## 后果

- 新增一列迁移 + 一个只补 NULL 的回补脚本；`market_sentiment_daily` 的"约 10 个数字/日"变成 12 列。
- 温度计卡片在**收盘口径**下可点（盘中不可点：没有可回放的同口径历史，点进去是另一种口径）。
- 趋势端点 `series` 追加字段（向后兼容），前端类型同步；`/sentiment/trends` 的 3 个分位指标不变
  （扩分位面是另一个决策，不在本篇）。
- 详情页的图与数都来自 `market_sentiment_daily`，盘后任务不跑时页面会如实停在上一交易日。
