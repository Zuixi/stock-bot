# 0012 不做自动下单

```
status:        accepted
date:          2026-10-12
supersedes:    -
superseded-by: -
```

## 背景

10 张图里"交易执行"只有标的分类 / 交易日志 / 持仓管理，"风险管理"只有"自动止损**触发与通知**"，
**全图无下单与券商对接**。但后续讨论会反复提议"接券商"。

## 决策

- 产品定位为**决策支持 + 记录复盘**。
- **不接受 / 不生成 / 不转发任何交易指令**。
- 所有"动作"止于**通知 + 待办**。
- 已知边界：闭环最后一步是人工（"执行价"依赖用户回填）。

## 影响

- 得到：无券商接口合规风险，无自动下单事故面。
- 代价：闭环最后一步是人工；记录质量取决于用户回填的自觉。

## 备选方案与否决原因

- **接券商 API** —— 合规门槛、接口分散、事故成本极高
- **半自动生成委托单草稿** —— 仍属投资建议边界，且草稿与下单只差一步
