# 0011 PIT 时点数据契约

```
status:        accepted
date:          2026-10-12
supersedes:    -
superseded-by: -
```

## 背景

策略回测 / 情绪-收益回测 / 历史同类政策回测 / 风控有效性审计全部依赖时点数据。
没有 PIT，回测会系统性偏高，而回测是本产品唯一能自证价值的地方。已知陷阱：报告期 vs 实际披露日、
申万分类调整无快照、退市股（幸存者偏差）、复权因子 / 停牌、参数优化无样本外。

## 决策

- **进入回测的序列必须带 `published_at`**——实际可得时点，不是报告期。
- 财务按**披露日**对齐。
- 分类归属改 **SCD2**（版本区间），不用当前快照回算历史（与 [ADR 0004](./0004-current-snapshot-not-backfilled.md) 同向）。
- 证券主表**保留退市标记**，退市股不静默消失。
- 上游口径修订须**留断点**（口径版本 + 断点标记）。

### 两条机械保证

1. 信号证据链中每个引用的 `published_at` **必须非空且 ≤ `effective_date`**；
   违反则**不生成信号并告警**，**绝不静默回退到 `period`**。
2. 回测须构造"**披露日 vs 报告期**"对照实验，且两者结果**必须有显著差异**——无差异说明 PIT 没生效。

## 影响

- 得到：回测可信，结论可被外部复核。
- 代价：采集与写入路径都要多算一个时点字段；既有表需评估补列
  （已知 `Stock.asof` 是开端，需扩到财务 / 分类 / 宏观指标）。

## 备选方案与否决原因

- **用报告期近似** —— 回测偷看未来：4 月才发的年报在 1 月就用上
- **不做回测就不需要 PIT** —— 策略引擎是产品出口，砍掉回测等于砍掉价值主张
