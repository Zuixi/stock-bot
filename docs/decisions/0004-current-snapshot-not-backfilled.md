# 0004 快照型分类数据只做"当日/向前"，不回算历史

> 追认补录（2026-09-23）。来源：`docs/references/best-practices.md`「当前快照型分类数据不提供历史」条目、`plans/2026-09-18-concept-boards-and-new-stocks.md`。

## 背景

概念成分、指数成分、股票名录都是**当前快照**：上游只给"今天谁在里面"，不给历史。而分析功能天然想按历史区间回看。

## 决策

- 历史部分**只做当日与向前累积**，绝不用当前快照回算过去
- 所有相关响应强制回传 `membership_as_of`，UI 明确标注"成分截至 X"
- 真历史由**追加式差分表**（`add`/`remove` 事件）从启用之日起自然积累

## 影响

- 得到：不会产出无法被检测的**前视偏差**（用今天的成分算昨天的行情）与**幸存者偏差**（被剔除的标的永远不在样本里）
- 代价：历史区间分析在启用初期样本不足，需要 UI 明示；用户"回看三个月板块表现"的需求短期无法满足
- 附带收益：差分表让"成分变更历史"成为可查询事实（`plans/2026-09-18` 中 T17 刻意延后的入口即基于此表）

## 备选方案与否决原因

- **用当前成分回算历史** —— 偏差不可检测，最危险的一类：数据看起来完整，结论系统性错误
- **外购历史成分数据** —— 成本与可得性均不确定，且仍是单一供应商口径
- **只存当前快照不留差分** —— 等于放弃"从今天起积累真历史"的机会
