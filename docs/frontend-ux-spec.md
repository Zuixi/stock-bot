# Stock Bot 前端 UX 规范（UX Spec）

## 1. 文档信息

- 文档版本：v1.0
- 日期：2026-04-07
- 对齐文档：`docs/frontend-service-prd.md`
- 目标：为视觉设计、交互设计、前端开发与测试提供统一执行标准

## 2. 设计原则

1. **先总览后下钻**：用户先看到市场全局，再进入分类与个股细节。
2. **数据优先于装饰**：强调可读性、可比性、可追溯性（数据时间戳必须显性）。
3. **低学习成本**：交互规则在不同页面保持一致（筛选、排序、搜索、收藏）。
4. **异常可恢复**：所有核心模块必须有加载态、空态、错误态和重试入口。
5. **移动端可浏览**：即使图表简化，核心查询和详情信息不可缺失。

## 3. 信息架构与导航规范

### 3.1 一级导航（桌面端）

- 市场（P0）
- 资讯（P1）
- 自选（P0）
- 工具（P1）
- 价值网（P2，占位）
- 赏金榜（P3，占位）

### 3.2 导航行为

1. 顶部导航固定（sticky），滚动不丢失主入口。
2. 当前页面高亮，且保留二级筛选状态。
3. 从列表进入详情后，返回时恢复原滚动位置与筛选条件。

## 4. 页面级 UX 规范

### 4.1 市场首页（Dashboard）

#### 4.1.1 页面结构

1. 顶部：全局搜索、用户入口、主题切换（预留）。
2. 模块 A：全球市场条（指数卡片横向排布）。
3. 模块 B：自选速览（3-10 条，默认按涨跌幅排序）。
4. 模块 C：行情中心（分布图、热力图、主力流入柱状图）。
5. 模块 D：A 股热门板块（卡片 + 迷你趋势线）。

#### 4.1.2 交互规则

1. 指数卡片支持点击跳转到分类页，自动带入市场维度参数。
2. 图表 hover 显示统一 tooltip 格式：名称、当前值、变化值、更新时间。
3. 图表与列表联动：点击热力图行业时，下方列表自动筛选。

#### 4.1.3 状态规范

1. 加载态：模块骨架屏，不阻塞其它模块先行渲染。
2. 空态：显示“暂无数据” + 刷新按钮 + 说明文本。
3. 错误态：显示错误摘要 + 重试按钮 + 错误追踪 ID（如可用）。

### 4.2 分类市场页

#### 4.2.1 页面结构

1. 顶部筛选条：交易所、一级行业、二级行业、板块、区间涨跌。
2. 次级控制条：排序字段、升降序、分页大小。
3. 主内容区：
   - 左侧（或上方）：分类分布图
   - 右侧（或下方）：股票列表表格

#### 4.2.2 列表列规范（P0）

- 股票名称
- 代码
- 交易所
- 行业/板块
- 最新价
- 涨跌幅
- 成交额
- 总市值
- 自选操作

#### 4.2.3 交互规则

1. 筛选变更后，重置分页到第一页。
2. 排序点击行为：`默认 -> 升序 -> 降序 -> 默认` 循环（或双态，需全站一致）。
3. 支持保留 URL 查询参数，便于分享和刷新恢复。
4. 点击股票名称进入详情页，新开页与当前页返回两种模式可配置。

### 4.3 个股详情页

#### 4.3.1 页面结构

1. 概览头部：名称、代码、交易所、行业、最新行情摘要、自选按钮。
2. 行情区：K 线 + 成交量 + 区间切换（1D/5D/1M/3M/6M/1Y）。
3. 基本面区：估值、盈利、成长、规模指标卡片。
4. 资讯区（P1）：公告、财报、新闻时间线。

#### 4.3.2 交互规则

1. 区间切换保留当前技术指标显示选项（如 MA 开关，P1）。
2. 基本面指标支持 tooltip 解释（字段定义和口径来源）。
3. 当字段缺失时显示 `--`，并在 tooltip 标记“数据暂不可得”。
4. 页面显著位置显示数据时间戳 `asof`。

### 4.4 自选页

1. 支持分组（默认分组 + 自定义分组，P1）。
2. 支持按涨跌幅、总市值、更新时间排序。
3. 支持一键移除与批量操作（P1）。
4. 自选为空时提供“去市场页添加”的引导按钮。

### 4.5 全局搜索（P1）

1. 支持代码、名称、拼音简码匹配。
2. 输入后 200ms 去抖，展示下拉候选。
3. 支持键盘上下选择与回车直达详情页。
4. 无结果时显示纠错建议（例如：检查代码格式）。

## 5. 组件与视觉行为规范

### 5.1 颜色与语义

1. 涨跌颜色全站统一，不允许局部反转。
2. 中性值（0 变化）使用灰色。
3. 风险提示/警告使用统一警示色与图标。

### 5.2 数值格式

1. 百分比保留 2 位小数（例如 `+2.35%`）。
2. 金额统一中文单位（万/亿）并支持 tooltip 显示原始值。
3. 时间统一使用本地时区和统一格式（例如 `YYYY-MM-DD HH:mm:ss`）。

### 5.3 表格规范

1. 表头吸顶（数据较长时）。
2. 固定关键列（名称、代码）以便横向滚动浏览。
3. 行 hover 显示快捷操作（加自选、查看详情）。

### 5.4 图表规范

1. 图表均提供导出图片（P1）与数据下载（P2）入口。
2. 图表标题必须包含维度说明和时间范围。
3. 图例切换状态应可持久化到当前会话。

## 6. 反馈与状态流规范

### 6.1 全局反馈

1. 成功操作：轻量 toast（不遮挡核心数据）。
2. 失败操作：toast + 内联错误（双通道提示）。
3. 异步请求超过 600ms 显示加载反馈，避免“无响应错觉”。

### 6.2 页面状态优先级

1. 首次加载失败：显示整页错误态。
2. 局部模块刷新失败：仅模块错误态，不影响页面其他区域。
3. 缓存过期刷新：优先显示旧数据 + “更新中”提示（SWR 体验）。

## 7. 响应式与可访问性

### 7.1 响应式断点建议

- Desktop：`>=1280`
- Tablet：`768-1279`
- Mobile：`<768`

### 7.2 移动端降级策略

1. 首页图表由多图并列降级为单列。
2. 表格降级为卡片流（保留关键指标）。
3. 保留搜索、分类、详情、自选四条主链路完整可用。

### 7.3 可访问性（A11y）

1. 所有交互元素具备可见焦点态。
2. 关键按钮/输入支持键盘访问。
3. 图标按钮必须有 `aria-label`。
4. 颜色对比满足基础可读标准。

## 8. 页面流程（核心用户路径）

1. 进入市场首页 -> 查看全局卡片 -> 点击行业热力图
2. 跳转分类页（自动带筛选参数）-> 调整排序/筛选
3. 点击某股票进入详情页 -> 查看行情 + 基本面
4. 点击“加入自选” -> 跳转自选页验证已加入

以上路径必须作为 P0 E2E 测试主路径。

## 9. UX 验收清单（交付前）

1. 首页、分类页、详情页、自选页均具备加载/空/错三态。
2. 筛选与排序在不同页面行为一致。
3. 详情页字段缺失显示规则一致（`--` + 解释）。
4. 数据时间戳展示清晰且位置稳定。
5. 全局搜索在桌面端与移动端均可用（P1 上线前必测）。
6. 关键路径交互无阻断（市场 -> 分类 -> 详情 -> 自选）。

## 10. 设计交付物要求（给 UX/UI）

1. 页面线框图（Low-Fi）：首页、分类、详情、自选。
2. 高保真稿（Hi-Fi）：桌面端优先，补齐移动端关键页。
3. 组件规范：卡片、表格、图表容器、筛选器、状态组件。
4. 交互说明：所有按钮/筛选/跳转/异常行为说明文档。
5. Design Token：颜色、字体、间距、圆角、阴影基础规范。
