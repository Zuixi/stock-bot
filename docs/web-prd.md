
# Frontend WebPage

## 1、Navigation Page

- 赏金榜：订单式情报收集打赏工具，支持需求发布，隐私保护下对接。（等其他功能基本完善后开启，实现情报众筹）
- 市场：上交所、深交所、北交所等全球市场看板。
- 资讯：上市公司、政府等影响股票波动的机构即时信息，包括公告、财报、政府经济数据、政策法规、新股发行等。
- 自定义：自选股等，按照个性化交易风格配置。
- 价值网：产业、行业、公司间的关联、传导关系图谱，如机构持仓情况。
- 工具库：募股说明书、财报等资料；公司财务造假案底库；行业报告；算法模型；智能体等。

## Market Page

### 1、Global Market
上交所、深交所、北交所，类FinScope

### 2、Industry Category
农林牧渔、基础化工等31个一级行业，种植业、渔业等137个二级行业，上市公司股票放在二级行业分类下；
支持31个一级行业、137个二级行业内部均支持按股票总市值由大到小动态排序，并指示出变动情况，包括位次及市值总和（↑2,或↓1）；
支持更换股票一级、二级行业分类；
支持在二级行业分类下扩展三级行业分类；

### 3、Industry Sector
种植业、渔业等137个二级行业；
支持所有二级行业分类按总市值动态排序，并指示出变动情况，包括位次及市值总和（↑2,或↓1）；
支持更好股票二级行业分类；

### 4、A-share Ranking
包括市值百强股票排行、半年/年利润百强股票排行、3/5/7年内市值跌幅排行、1/2/3年内市值涨幅排行；
支持指示较上个周期变动情况，包括排序、市值；
