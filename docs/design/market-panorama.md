# A股全景：市场结构脉搏（2026-10-19）

> 目标：把 `/market` 的「A股全景」从**五张今日快照**升级为**可回看、能解释变化**的
> 市场结构面板。数据口径与取舍见 [ADR 0023](../decisions/0023-market-panorama-daily-snapshots.md)。

## 1. 一屏要回答的三个问题

1. **今天是什么结构？** 普涨 / 结构 / 普跌 / 抱团（广度 × 集中度 × 中位方向）。
2. **比昨天变了什么？** 上涨/下跌家数、中位涨跌幅、成交额、Top 行业资金流、行业排名。
3. **过去 20/60/120/250 天怎么走到这里？** 广度轨迹 + Top3 集中度轨迹。

## 2. 数据层

| 表 / 源 | 粒度 | 用途 | 缺失语义 |
|---|---|---|---|
| `market_breadth_daily` | 1 行/日 | 上涨/下跌/平盘、涨跌停、中位/均值涨跌幅、成交额 | 无行 = 没回补；不补 0 |
| `market_breadth_bucket_daily` | 11 行/日 | 与 `/market/distribution` 同口径的 11 桶 | 固定 11 桶，0 是真实 0 |
| `market_industry_daily` | 31 行/日 | 申万一级涨跌幅、宽度、成交额、涨停数、排名 | 归属是当前快照 |
| `sector_moneyflow_snapshots` | 板块/日 | 资金流 Top / 连续性 | 只认 `eod_full`；无完整日 = null |

- 广度口径：上涨 `pct_chg >= 1%`、平/微涨 `0 <= pct_chg < 1%`、下跌 `<0`（与 11 桶卡一致）。
- 行业归属：`attribution='current_sw_snapshot'`；UI 固定提示"按当前申万快照回溯"。
- 回补：`backend/scripts/backfill_market_panorama.py`；默认 2025-10-15（限价安全窗口）起，
  幂等、支持 `--dry-run`。
- 续写：`market_panorama_daily` job（Mon-Fri 17:25，晚于 16:30 行情 / 16:50 限价）
  调同一 `market_panorama_ingest_service.refresh_day`；纯本地、幂等，停摆后迟到也补跑。

## 3. 读面

`GET /api/v1/market/panorama?days=20|60|120|250`

- 响应：`as_of / expected_as_of / stale / lag_days / window`、`breadth.latest|previous|series`、
  `buckets`、`industries`（最新 31 + `rank_delta`）、`structure.current|series`、
  `flows`（`as_of/available_from/top_in/top_out`）、`freshness`。
- 一次请求 5 组范围查询；结构聚合在 SQL 里算 Top3/HHI/离散度，不把 7,750 行行业明细
  读进 Python；Redis 120s。
- 实测冷请求 20D 19ms / 60D 21ms / 120D 24ms / 250D 31ms；250D 99KB；缓存命中 4–6ms。
- 前端**不轮询**（日级数据）；`keepPreviousData` 切范围不闪骨架。

## 4. UI：一条仪表带，不是第五张卡

```
市场结构 全景脉搏                         20D 60D 120D 250D  数据截至 …
普跌 / 结构 / 普涨 / 抱团
上涨占比 37.8% · Top3 成交额 34.4% · 离散度 1.08
┌ 广度 × 集中度（罗盘） ┐  ┌ 上涨/下跌 ┐ ┌ 中位涨跌幅 ┐
│ 60 日轨迹 + 今日点    │  │ +1834     │ │ +0.47%     │
│ 四象限：抱团/普涨/…   │  ├───────────┤ ├───────────┤
└───────────────────────┘  │ 成交额     │ │ 主力净流入 │
                           └───────────┘ └───────────┘
结构状态 = 广度 + Top3 集中度（启发式）   行业归属：当前申万快照
```

- **罗盘**：x = 上涨占比，y = Top3 成交额占比；60 日轨迹用低透明度线 + 小点，今日点
  用状态色放大；四象限标注"抱团/普涨/普跌/结构"。
- **4 个 KPI**：上涨/下跌、中位涨跌幅、成交额、主力净流入 Top；每个带"较昨日"，
  前三个带 5 日 SVG sparkline（不启 ECharts 实例，避免 4 套 canvas）。
- **状态色**：普涨红、普跌绿、抱团橙、结构强调色；状态是描述性标签，固定"不是交易信号"。
- **移动端**：罗盘 + 2×2 KPI 单列堆叠；390 无横向溢出。

## 6. 明确不做

- 跨卡行业筛选（`?sw=` 过滤热力图/资金流/网格）——下一阶段；
- 热门板块"新进/连续/掉出"——需要 `sector-trends` 与榜单交集，下一阶段；
- 热力图 5D/20D 收益区间——需要逐股窗口收益，成本高于本轮价值；
- 个股层 5,500 行历史落表——只按日现算，不物化。
